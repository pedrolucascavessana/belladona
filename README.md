# BellaDona — Controle da Minha Loja

Sistema de gestão com abas VENDA, COMPRA, ESTOQUE e PRODUTO.

## Recursos

- Cadastro e edição de produtos, preços e estoque mínimo.
- Registro de vendas e compras com atualização automática de estoque.
- Bloqueio de vendas sem saldo disponível.
- Histórico e estorno de movimentações.
- Busca, alertas de reposição e exportação CSV.
- Cópia de segurança e restauração por arquivo JSON.

## Como usar

Abra `index.html` em um navegador moderno. Não precisa instalar dependências.

## Armazenamento

Esta versão salva os registros no armazenamento local do navegador. Os dados não são enviados ao GitHub e não são sincronizados entre dispositivos. Use “Salvar cópia” regularmente. Para transferir os registros para outro dispositivo ou endereço, salve uma cópia e use “Restaurar cópia”.

## Publicação

Este repositório contém os arquivos do site. Enviar os arquivos ao GitHub não ativa automaticamente um endereço de hospedagem. A hospedagem deve ser configurada separadamente.
